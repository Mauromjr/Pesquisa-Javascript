## O que é JavaScript?

JavaScript é uma linguagem de programação muito utilizada no desenvolvimento web. Ela permite criar páginas interativas, dinâmicas e modernas.

Atualmente, JavaScript pode ser usado tanto no **frontend**, que é a parte visual dos sites, quanto no **backend**, que é a parte do servidor, principalmente com o uso do Node.js.

---

## História do JavaScript

JavaScript foi criado em 1995 por **Brendan Eich**, enquanto trabalhava na empresa Netscape.

A linguagem foi desenvolvida inicialmente para tornar as páginas da web mais interativas. Com o tempo, JavaScript se tornou uma das linguagens de programação mais populares do mundo.

Apesar do nome parecido, **JavaScript não é a mesma linguagem que Java**. Elas possuem propostas, estruturas e usos diferentes.

---

## Principais características

* Linguagem interpretada;
* Tipagem dinâmica;
* Muito usada no desenvolvimento web;
* Funciona diretamente nos navegadores;
* Pode ser usada no servidor com Node.js;
* Permite programação orientada a objetos;
* Permite programação funcional;
* Possui grande comunidade;
* Conta com muitos frameworks e bibliotecas.

## Exemplos de código

### Exemplo 1: Olá, mundo

```javascript
console.log("Olá, mundo!");
```

### Exemplo 2: Variáveis

```javascript
let nome = "JavaScript";
let anoCriacao = 1995;

console.log(nome + " foi criado em " + anoCriacao);
```

### Exemplo 3: Função

```javascript
function somar(a, b) {
  return a + b;
}

console.log(somar(5, 3));
```

### Exemplo 4: Condicional

```javascript
let idade = 18;

if (idade >= 18) {
  console.log("Maior de idade");
} else {
  console.log("Menor de idade");
}
```

## Áreas de aplicação

JavaScript pode ser utilizado em várias áreas, como:

* Desenvolvimento de sites;
* Desenvolvimento de sistemas web;
* Aplicações frontend;
* Aplicações backend;
* Desenvolvimento de APIs;
* Aplicativos móveis;
* Jogos;
* Automação;
* Aplicações desktop.

---

## Frameworks e bibliotecas populares

Algumas ferramentas muito usadas com JavaScript são:

* **React**: criação de interfaces web;
* **Vue.js**: criação de interfaces modernas;
* **Angular**: desenvolvimento de aplicações web completas;
* **Node.js**: uso do JavaScript no backend;
* **Express.js**: criação de servidores e APIs;
* **React Native**: desenvolvimento de aplicativos móveis.

---

## Vantagens do JavaScript

* É uma linguagem muito popular;
* Fácil de começar a aprender;
* Funciona nos principais navegadores;
* Pode ser usada no frontend e no backend;
* Possui muitas bibliotecas e frameworks;
* Tem uma comunidade grande;
* É muito utilizada no mercado de trabalho.

---

## Desvantagens do JavaScript

* Pode apresentar comportamentos inesperados por causa da tipagem dinâmica;
* Em projetos grandes, pode ficar difícil de organizar sem boas práticas;
* Pode ter problemas de segurança se o código não for bem feito;
* Depende do navegador em algumas situações;
* Algumas mensagens de erro podem ser difíceis para iniciantes.

## Curiosidades

* JavaScript foi criado em poucos dias;
* Inicialmente, a linguagem se chamava Mocha;
* Depois passou a se chamar LiveScript;
* O nome JavaScript foi adotado posteriormente;
* Mesmo tendo “Java” no nome, JavaScript é uma linguagem diferente de Java;
