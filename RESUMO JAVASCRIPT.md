## 1. História do JavaScript

O JavaScript foi inventado em 1995, no começo da internet, onde a velocidade não passava de KB, e os sites eram muito simples, onde na maioria das vezes, eles mostravam só texto, imagens e links, não tinha nada muito visual para interagir com quem tava mexendo.

A ideia do JavaScript foi justamente deixar as páginas mais simples, e melhoradas. Com ele, os desenvolvedores passaram a conseguir criar botões com ações, validações de formulários, mensagens na tela e outros recursos que melhoravam a experiência de quem acessava um site.

No começo, o JavaScript era usado principalmente dentro dos navegadores. Com o passar do tempo, a linguagem evoluiu e passou a ser usada para mais tarefas, além de ainda ser usada em navegadores. Hoje, está presente em frontends de sites, assim como usada em backends com o Node.js, automoções e em mais áreas.

Outro ponto importante é que o JavaScript passou a seguir uma padronização chamada ECMAScript. Essa padronização ajuda a manter a linguagem organizada e compatível entre diferentes navegadores e plataformas.

## 2. Criador e contexto de criação

O criador do JavaScript foi Brendan Eich, que trabalhava na empresa Netscape. E uma curiosidade é que a linguagem foi criada para ser usada no navegador Netscape Navigator, que era um dos navegadores mais conhecidos nessa época.

O Brendan Eich queria uma linguagem que fosse mais simples e que permitisse criar interações nas páginas. Por isso, ele desenvolveu a primeira versão do JavaScript em pouco tempo.

Antes de receber o nome JavaScript, a linguagem teve outros nomes. Primeiro, ela foi chamada de Mocha. Depois, passou a se chamar LiveScript. Mais tarde, recebeu o nome JavaScript, em um período em que a linguagem Java estava muito popular.

Apesar do nome parecido, JavaScript não é a mesma coisa que Java. O nome acabou causando confusão em muitas pessoas, mas as duas linguagens possuem objetivos e formas de funcionamento diferentes.

## 3. Principais características da linguagem

JavaScript é uma linguagem muito conhecida por ser flexível e muito importante para o desenvolvimente de front-end. Uma das suas principais características se da por ela poder ser executada diretamente em muitos navegadores.

A linguagem possui tipagem dinâmica. Significa, que ela é uma linguagem mais simples de se programar, pois não é obrigatório definitr o tipo de uma variável quando você cria ela. Por exemplo, a varíavel q vc criou pode receber um texto uma hora, e na outra um número.

JavaScript também permite trabalhar com diferentes estilos de programação, como programação orientada a objetos e programação funcional. Além disso, possui suporte a funções, eventos, manipulação de páginas HTML e comunicação com servidores.

Outra característica importante é sua grande quantidade de bibliotecas e frameworks. Ferramentas como Node.js, Vue.js, Angular, entre outras, que são ferramentas muito usadas hoje em dia no mercado da programação.

Por ser uma linguagem muito popular, JavaScript também possui uma comunidade grande. Isso facilita encontrar materiais de estudo, exemplos de código, documentação e soluções para problemas comuns.

## 4. Diferença entre JavaScript e Java

Mesmo tendo nomes parecidos, JavaScript e Java são linguagens diferentes.

JavaScript é muito usado no desenvolvimento web. Ele aparece bastante no frontend, que é a parte visual e interativa dos sites, mas também pode ser usado no backend com Node.js. A linguagem é conhecida por ser flexível, ter tipagem dinâmica e ser muito usada nos navegadores.

Java, por outro lado, é uma linguagem mais "séria", usada em sistemas de bancos, programas de grande porte. Java diferente do JavaScript, quando é criado a variável, o tipo dela tem q ser definido na hora da criação, sendo muito mais rígida com isso, e verificando antes de executar o programa.

Outra diferença está na forma como as linguagens são executadas. O Java precisa ser compilado para o bytecode e depois rodar no jvm(maquina virtual java). Já o JavaScript é executado pelos navegadores, ou fora deles com o node.js.

Portanto, JavaScript não é uma versão do Java. São linguagens diferentes, com usos, características e ecossistemas próprios.
